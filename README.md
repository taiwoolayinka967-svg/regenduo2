# Alex Morgan — Portfolio Website

A production-style responsive portfolio built with:
- Semantic HTML5
- Modern CSS3 (Grid, Flexbox, clamp, custom properties)
- Vanilla JavaScript ES6+
- No frameworks or external UI libraries

## Run
Open `index.html` in a browser. For best local development, use any simple static server.

## Included interactions
- Responsive mobile navigation
- Sticky/blurred header
- Dark/light theme with localStorage
- Project category filtering
- Project detail modal
- FAQ accordion
- Scroll reveal animations
- Accessible form validation + toast/status feedback
- Reduced-motion support

## Customize
Replace the sample name, project copy, email, social links, and visual mockups with your own content. CSS variables at the top of `css/style.css` control the main visual system.
